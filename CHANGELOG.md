# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [SemVer](https://semver.org/lang/ru/).

У компонентов свои версии: `bixis-term` (терминал) и `bixis` (композитор).

## [Unreleased]

### bixis

- Клавиши громкости, включая `Fn` + клавиши с динамиком: изменение на 5% и mute
  для устройства вывода по умолчанию. При удержании громкость меняется повторно,
  mute срабатывает один раз. Используется `wpctl`, при его отсутствии — `pactl`;
  команды запускаются без блокировки композитора. Бинды доступны и в старых конфигах,
  их можно переопределить действиями `volume_up`, `volume_down`, `volume_mute`.
- `autostart = КОМАНДА` (можно несколько строк): фоновые программы при старте.
  В пример конфига добавлены агент polkit (окно пароля для `pkexec`, например для VPN)
  и `dbus-update-activation-environment` для порталов и D-Bus-активации.
- Окна фиксированного размера (окно пароля, небольшие утилиты) больше не растягиваются:
  они появляются в своём размере по центру текущего слота и получают фокус. GTK сообщает
  размер уже после первого коммита, поэтому проверка повторяется на каждом коммите.
- 4K: `scale = auto` (теперь по умолчанию) даёт 200% мониторам от 3840 пикселей в ширину
  и экранам от 180 DPI, остальным 100%.
- Режим монитора по умолчанию — родное разрешение с максимальной частотой
  (4K-мониторы с 30 Гц в «предпочтительном» режиме получают 60 Гц).
- Опция `[output] mode = ШИРИНАxВЫСОТА[@ГЦ]`; в окне и headless-режиме задаёт произвольный размер.
- В лог пишется выбранный режим и масштаб каждого выхода.
- Окно процесса, запущенного слотом или `spawn`, попадает туда, откуда его запустили,
  даже если по `app_id` оно подходит другому слоту. Раньше `spawn bixis-term`
  уводил окно в слот терминала вместо текущего.

### bixis-term

- Исправлен пропуск кадра при возврате к содержимому старого SHM-буфера:
  damage теперь считается относительно последнего отправленного кадра,
  независимо от того, какой буфер выбран для рисования.
- Перерисовываются участки строк с учётом широких символов и выступающих глифов;
  изменения в разных строках отправляются отдельными прямоугольниками damage.
  Фон соседних ячеек одного цвета заполняется за один проход.
- Отправка clipboard идёт неблокирующе через `poll`: медленный получатель не
  задерживает ввод, а текущая передача сохраняет текст при смене выделения.
  Чтение и запись получают ограниченный объём работы за итерацию цикла.
- Очередь PTY хранит смещение вместо сдвига остатка после каждой частичной записи;
  крупные буферы очереди и вставки освобождаются после завершения передачи.
- Обработанное изменение заголовка фоновой вкладки больше не вызывает повторные
  проверки отрисовки; повтор того же OSC-заголовка не помечается изменением.
- Добавлены тесты отрисовки и I/O под ASan/UBSan, бенчмарки `make -C term bench`.
- События мыши для приложений (1000/1002/1003, SGR 1006): колесо передаёт
  координаты указателя вместо стрелок, если программа включила режим мыши.
  Исправляет попадание прокрутки в поле ввода TUI-приложений.
  `Shift` сохраняет выделение, вставку и прокрутку истории средствами терминала.
- HiDPI на композиторах без `preferred_buffer_scale` (например FeatherDE):
  масштаб берётся из `wl_output.scale` выходов, на которых окно. На 4K со 200%
  текст теперь рисуется в полном разрешении, а не растягивается.
- `Ctrl+1…9` — перейти к вкладке по номеру (раньше только `Ctrl+Shift+1…9`).

## [bixis 0.1.0] — 2026-11-05

Первый MVP композитора `bixis` на wlroots 0.19.

### Добавлено

- Слоты: каждое приложение занимает весь экран, горячая клавиша показывает его слот
  или запускает приложение, если окна ещё нет. По умолчанию слоты `terminal` (`bixis-term`),
  `browser` (`firefox`), `messenger` (`telegram-desktop`), `video` (`mpv`).
- Окно попадает в слот по `app_id`, затем по PID запущенной команды, затем в слот,
  который сейчас запускается. Последнее нужно для snap и flatpak, где окно создаёт другой процесс.
- Окна разворачиваются на весь выход в состоянии maximized + tiled. Рамки клиентов
  отключены через `xdg-decoration`. Диалоги центрируются поверх своего слота,
  popup'ы не выходят за край экрана.
- Конфиг `~/.config/bixis/config` в формате INI: модификатор, стартовый слот, раскладки
  и опции xkb, автоповтор, масштаб, цвет фона, слоты (`exec`, `app_id`) и бинды
  (`slot`, `spawn`, `close`, `cycle`, `reload`, `exit`). Ошибки показываются с номером строки.
  Встроенный конфиг по умолчанию генерируется из `compositor/bixis.conf`.
- Бинды распознаются по латинскому символу клавиши, поэтому работают в любой раскладке.
  Отпускание клавиши, нажатие которой забрал бинд, приложению не передаётся.
- Перечитывание конфига по `mod+shift+r` и `SIGHUP`, без перезапуска и без потери окон.
- Протоколы: `xdg-shell` v6, `wl_compositor` v6, буфер обмена и primary selection,
  `viewporter`, `presentation-time`, `fractional-scale`, `single-pixel-buffer`, `cursor-shape`,
  `xdg-output`, `screencopy`, `virtual-keyboard`.
- Переключение VT (`Ctrl+Alt+F1…F12`), сессия для дисплейного менеджера
  (`share/wayland-sessions/bixis.desktop`), запуск в окне внутри другого Wayland.
- Дочерним процессам выставляются `XDG_CURRENT_DESKTOP=bixis`, `MOZ_ENABLE_WAYLAND=1`,
  `QT_QPA_PLATFORM=wayland`, `ELECTRON_OZONE_PLATFORM_HINT=wayland`, `GDK_BACKEND=wayland`.

## [bixis-term 0.1.0] — 2026-11-05

Первый MVP терминала `bixis-term`.

### Добавлено

- Wayland-клиент: `xdg-shell`, серверные рамки через `xdg-decoration` (если композитор умеет),
  форма указателя через `cursor-shape-v1`, HiDPI через `preferred_buffer_scale`.
- Отрисовка в `wl_shm` с двумя буферами; перерисовываются только строки,
  отличающиеся от последнего кадра в этом буфере. Кадры синхронизированы с vblank.
- Шрифты через fontconfig + FreeType: regular/bold/italic/bold-italic,
  синтетический bold/italic, fallback-шрифты для недостающих символов, кэш глифов.
- Эмулятор VT: собственный парсер (ESC, CSI, OSC; DCS/APC/PM игнорируются), UTF-8,
  широкие символы (`wcwidth`), основной и альтернативный экраны (47/1047/1049),
  область прокрутки, origin mode, insert mode, табуляторы, DEC line drawing,
  SGR (bold, dim, italic, underline, reverse, invisible, strike, 16/256/truecolor),
  ответы на DA1/DA2/DSR, заголовок окна через OSC 0/2,
  режимы курсора и клавиатуры приложений, bracketed paste (2004), focus events (1004),
  форма курсора (`DECSCUSR`).
- Скроллбэк на 5000 строк в кольцевом буфере (строки хранятся обрезанными).
- Вкладки: `Ctrl+Shift+T` — новая, `Ctrl+Shift+W` — закрыть,
  `Ctrl+Tab` / `Ctrl+Shift+Tab` / `Ctrl+PgUp` / `Ctrl+PgDn` — переключить,
  `Ctrl+Shift+1…9` — перейти к вкладке по номеру. Полоска вкладок видна только при двух и более вкладках.
- Клавиатура через xkbcommon: автоповтор с параметрами композитора,
  Ctrl-сочетания и бинды работают в любой раскладке (берётся латинская).
- Выделение мышью, `Ctrl+Shift+C` — копировать, `Ctrl+Shift+V` и `Shift+Insert` — вставить.
- Прокрутка: колесо мыши, `Shift+PgUp` / `Shift+PgDn`, `Shift+Home` / `Shift+End`;
  в альтернативном экране колесо посылает стрелки (less, man).
- Масштаб шрифта: `Ctrl+=` / `Ctrl+-` / `Ctrl+0`.
- Настройка через `term/config.h`: шрифт, размер, отступы, палитра, скроллбэк, бинды.
- Каждая строка экрана хранит верхнюю границу занятых ячеек, поэтому прокрутка и запись
  в скроллбэк не зависят от ширины окна. Парсер обрабатывает 100–125 МБ/с.
- `make check`: тесты эмулятора под AddressSanitizer и UBSan.
- `make install` ставит бинарник и `bixis-term.desktop`; поддерживаются `PREFIX` и `DESTDIR`.
- Документация: `README.md`, `docs/MANUAL.md`, `ROADMAP.md`.
