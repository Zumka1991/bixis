# Bixis — Roadmap

Bixis — минималистичная Wayland-оболочка: собственный терминал со вкладками
и три приложения по горячим клавишам (браузер, мессенджер, видеоплеер).
Никаких панелей, анимаций и эффектов. Цель — минимум зависимостей, минимум
памяти, минимум задержки.

## Принципы

- Язык — C11, сборка — `make`, никаких тяжёлых фреймворков.
- Рисуем только то, что изменилось, и не чаще vblank (frame callbacks).
- Ни одного таймера «на всякий случай»: всё через `poll`.
- Каждая зависимость должна окупаться. Сейчас это `wayland-client`,
  `xkbcommon`, `freetype2`, `fontconfig`.

## Компоненты

| Компонент     | Что это                                        | Статус         |
|---------------|------------------------------------------------|----------------|
| `bixis-term`  | Терминал (Wayland-клиент) со вкладками         | v0.1 — MVP     |
| `bixis`       | Композитор на wlroots: слоты + горячие клавиши | не начат       |

## bixis-term

### v0.1 — MVP (готово)

- [x] Окно Wayland через `xdg-shell`, рамки от сервера (`xdg-decoration`), если есть
- [x] Отрисовка в `wl_shm` с двойной буферизацией; перерисовываются только изменённые строки
- [x] Шрифты: fontconfig + FreeType, кэш глифов, bold/italic, fallback-шрифты
- [x] PTY (`forkpty`), `TERM=xterm-256color`
- [x] Собственный парсер VT (state machine по схеме DEC/Paul Williams), UTF-8, широкие символы
- [x] Основной и альтернативный экраны, область прокрутки, сохранение курсора,
      16/256/truecolor, DEC line drawing, форма курсора (`DECSCUSR`)
- [x] Скроллбэк (кольцевой буфер, строки хранятся без хвостовых пробелов)
- [x] Вкладки: создание, закрытие, переключение, полоска вкладок при >1 вкладке
- [x] Клавиатура через xkbcommon: автоповтор, Ctrl-сочетания работают в русской раскладке
- [x] Выделение мышью, копирование и вставка через буфер обмена, bracketed paste
- [x] Масштаб шрифта на лету, HiDPI (`preferred_buffer_scale`)
- [x] Настройка через `config.h` (в стиле suckless)

### v0.2 — Удобство

- [ ] Конфиг во время работы: `~/.config/bixis/term.conf` (шрифт, цвета, бинды), перечитывание по `SIGHUP`
- [ ] Primary selection (`zwp_primary_selection`) + вставка средней кнопкой
- [ ] Выделение слова и строки двойным и тройным кликом
- [ ] Передача событий мыши приложениям (режимы 1000/1002/1003/1006)
- [ ] Synchronized output (режим 2026) — без мерцания в nvim
- [ ] Индикатор активности в фоновых вкладках
- [ ] Новая вкладка открывается в текущей директории (OSC 7)
- [ ] HiDPI на композиторах без `preferred_buffer_scale`: `wl_output.scale`, `fractional-scale-v1`

### v0.3 — Корректность

- [ ] Reflow строк при изменении ширины окна
- [ ] Комбинируемые символы и графемные кластеры (ZWJ, вариационные селекторы)
- [ ] Цветные эмодзи (CBDT/COLR)
- [ ] OSC 52 (буфер обмена из приложений, например из tmux или nvim)
- [ ] Прохождение основных разделов `vttest`

### v0.4 — Скорость и память

- [x] Строки знают свою занятую длину: прокрутка и скроллбэк стоят O(текст), а не O(ширина)
- [ ] Бенчмарки (`vtebench`, `cat` большого файла) и профилирование. Сейчас 100–125 МБ/с на обычном тексте
- [ ] Перерисовка по отрезкам ячеек, а не целыми строками
- [ ] Упаковка ячейки до 12 байт, сжатие скроллбэка
- [ ] Отложенная отрисовка при потоке вывода (ограничение по кадрам)

## bixis (композитор)

### v0.5 — MVP композитора

- [ ] Основа на wlroots (`wlr_scene`), запуск из TTY через libseat
- [ ] Модель «один экран — одно приложение»: 4 слота (терминал, браузер, мессенджер, видео)
- [ ] Горячая клавиша: показать слот или запустить приложение, если оно не запущено
- [ ] Direct scanout полноэкранного клиента (без копирования кадра)
- [ ] Popup'ы и диалоги поверх текущего слота

### v0.6 — Совместимость

- [ ] Буфер обмена и primary selection между приложениями
- [ ] `linux-dmabuf`, `viewporter`, `presentation-time`, `fractional-scale`
- [ ] Несколько мониторов (слот на каждый выход)

### v0.7 — Конфиг

- [ ] `~/.config/bixis/config`: модификатор, бинды, команды запуска слотов
- [ ] Перечитывание конфига по `SIGHUP`
