# Bixis

Минималистичная Wayland-оболочка на C. Собственный терминал со вкладками
и три приложения по горячим клавишам: браузер, мессенджер, видеоплеер.
Без панелей, анимаций и эффектов: только то, что нужно, и как можно быстрее.

Готовы композитор **`bixis`** (v0.1) и терминал **`bixis-term`** (v0.1).
4K поддерживается из коробки: масштаб 200% выставляется сам, текст рисуется в полном разрешении.

## bixis

- На экране всегда одно приложение во весь экран, без панелей и рамок
- `Super+1…4` — терминал, браузер, мессенджер, видео: показать или запустить
- Клавиши громкости (в том числе через `Fn`): шаг 5%, удержание и mute; нужен `wpctl` или `pactl`
- Конфиг `~/.config/bixis/config` (INI): слоты, бинды, раскладки, масштаб, режим монитора;
  перечитывается на лету
- 4K: масштаб 200% и 60 Гц выбираются автоматически
- wlroots 0.19, около 64 КБ бинарник; запуск из консоли, с экрана входа или в окне

## bixis-term

- Собственный парсер VT, 16/256/truecolor, альтернативный экран, скроллбэк
- Вкладки, выделение мышью, буфер обмена, bracketed paste
- Горячие клавиши работают в любой раскладке
- Перерисовываются изменённые участки строк, кадры синхронизированы с vblank
- Около 100 КБ бинарник, около 14 МБ RSS, парсер выдаёт больше 100 МБ/с
- Зависимости: `wayland-client`, `xkbcommon`, `freetype2`, `fontconfig`

## Быстрый старт

Ubuntu / Debian:

```bash
sudo apt install build-essential pkgconf libwayland-dev libwayland-bin wayland-protocols libxkbcommon-dev libfreetype-dev libfontconfig-dev libwlroots-0.19-dev grim wl-clipboard wireplumber policykit-1-gnome dbus-bin seatd fonts-dejavu
```

```bash
make && sudo make install
```

Выбери сессию **Bixis** на экране входа или запусти `bixis` из текстовой консоли.
Попробовать в окне внутри текущей сессии:

```bash
./compositor/build/bixis
```

Терминал отдельно, в любом Wayland:

```bash
bixis-term
```

Клавиши `bixis`: `Super+1…4` — слоты, `Super+Q` — закрыть окно, `Super+Shift+R` — перечитать
конфиг, `Super+Shift+E` — выход, `Print Screen` — снимок в `~/Pictures` и в буфер обмена (нужны `grim` и `wl-clipboard`).
Клавиши `bixis-term`: `Ctrl+Shift+T` — новая вкладка, `Ctrl+Tab` — следующая,
`Ctrl+1…9` — перейти к вкладке по номеру, `Ctrl+Shift+C` / `Ctrl+Shift+V` — копировать / вставить,
`Shift+PgUp` — история. На основном экране `Shift` со стрелками выделяет текст;
в полноэкранных приложениях клавиши передаются самому приложению.
В Bash команда `/set_title Название` задаёт имя текущей вкладки;
`/set_title` без аргументов возвращает автоматический заголовок.
